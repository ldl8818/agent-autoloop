# 协作方法来源

本项目采用 Solo to Team 的派收、交付证据、新手操作说明及脱敏案例结构，并由现有事件、worker、决定卡和项目检查入口实施。现行约定只在[维护工作流](维护工作流.md)维护；本页记录来源。

- 来源：https://github.com/dabingfy-dot/solo-to-team-skills
- 固定提交：`bc9c19458e9d4afe42e506fc65673a68c26c6a56`。
- 采用范围：任务责任与交付契约；接单、收到成果、验收分别取证；原承诺和改期记录；同版本证据复用；需要本人操作时的步骤写法；问题、改法、结果及未证明部分的案例结构。
- 本地适配：状态由程序控制，调度和记录复用中台，外部文字只作资料。运行不依赖 GitHub，也不自动更新上游方法。后续改动先比较该提交与新来源，再决定采纳。
