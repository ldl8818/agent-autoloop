## 怎么使用

可以在已有对话直接说“核对代理监测和常驻服务，给我完整诊断报告”，或提出 caipiao 的源码维护任务。主 Agent 确认项目、目标、交付物和完成标准后登记。信息不足时补齐范围；没有登记固定入口的项目先完成接入。

proxy 当前只读入口覆盖三个 Autoloop 执行池载入、原监测时效和全部活动告警，按可信只读策略自动交接。caipiao 的源码修改仍需本人批准，复用原隔离开发和交付流程。交付报告不代表原告警修复，源码交付也不代表自然业务已经恢复。

## 常驻服务

新增常驻服务为0，继续复用任务调度与 AI 助手、业务定时任务执行、网站故障自动修复三个执行池。没有增加 LaunchAgent、卡片监听或定时轮询；岗位是一轮一轮的任务进程。规则由35条增至37条，Agent 数22、来源数6保持。

原代理监测、独立哨兵、通知补发、外部心跳及原业务定时任务继续承担原职责。它们负责独立判活和送达，合并到模型链会丢失故障隔离，因此保留。
